# Changelog Examples

只描述本次发布后的最终状态，不记录发布前的调整过程。

## 合并同一发布事项

错误：

```markdown
## [1.1.0] - 2026-08-26

### Added

- 添加用户登录功能。

### Changed

- 调整登录表单字段顺序。

### Fixed

- 修复登录失败提示。
```

正确：

```markdown
## [1.1.0] - 2026-08-26

### Added

- 添加用户登录功能，支持账号密码认证和明确的登录失败提示。
```

## 已发布能力的后续变化

`1.0.0` 已经发布“项目初始化配置”，后续改为分层配置时使用：

```markdown
## [1.1.0] - 2026-08-26

### Changed

- 项目初始化配置改为使用分层配置文件。

## [1.0.0] - 2026-05-20

### Added

- 添加项目初始化配置和基础命令。
```
